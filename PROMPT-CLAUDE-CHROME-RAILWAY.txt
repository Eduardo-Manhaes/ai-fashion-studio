═══════════════════════════════════════════════════════════
TAREFA 1: ADICIONAR REDIS DATABASE
═══════════════════════════════════════════════════════════

**Ação:**

1. Na dashboard do Railway, localize o botão **"New"**
   (geralmente canto superior direito ou centro da tela)

2. Clique em **"New"** → Selecione **"Database"**

3. Na lista de databases, clique em **"Add Redis"**

4. Aguarde ~30 segundos para Railway provisionar o Redis

5. **VERIFIQUE:**
   - Clique no serviço PRINCIPAL (servidor Node.js)
   - Vá na aba "Variables"
   - Confirme que `REDIS_URL` apareceu automaticamente
   - Deve começar com `redis://default:...`

**Me responda:**
✅ "Redis criado e REDIS_URL está em [nome-do-serviço-principal]"

═══════════════════════════════════════════════════════════
TAREFA 2: CRIAR SERVIÇO WORKERS
═══════════════════════════════════════════════════════════

**Ação:**

1. Clique em **"New"** novamente

2. Selecione **"GitHub Repo"**

3. Conecte ao repositório:
   - Procure por "Eduardo-Manhaes/ai-fashion-studio"
   - Se não aparecer, clique em "Configure GitHub App" para dar permissão
   - Selecione o repositório

4. **Configure o serviço:**
   - **Service Name:** Digite exatamente `workers`
   - **Root Directory:** Deixe VAZIO (ou apenas `/`)
   - **Build Command:** `npm install`
   - **Start Command:** `npm run workers`
   - **Environment:** production (mesmo do serviço principal)

5. Clique em **"Deploy"** ou **"Add Service"**

**Me responda:**
✅ "Serviço 'workers' criado com start command 'npm run workers'"

═══════════════════════════════════════════════════════════
TAREFA 3: COPIAR VARIÁVEIS DE AMBIENTE
═══════════════════════════════════════════════════════════

**Ação:**

**PARTE A: Copiar do serviço principal**

1. Clique no serviço PRINCIPAL (servidor Node.js, NÃO o workers)

2. Aba "Variables"

3. **COPIE os VALORES** destas 3 variáveis (anote temporariamente):
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `FAL_API_KEY`

**PARTE B: Colar no serviço workers**

1. Clique no serviço **"workers"**

2. Aba "Variables"

3. Para CADA variável, clique **"New Variable"**:

   ```
   Nome: SUPABASE_URL
   Valor: [cole o valor que você copiou]
   → Save

   Nome: SUPABASE_SERVICE_ROLE_KEY
   Valor: [cole o valor que você copiou]
   → Save

   Nome: FAL_API_KEY
   Valor: [cole o valor que você copiou]
   → Save
   ```

4. **VERIFIQUE:** `REDIS_URL` deve já estar lá automaticamente
   - Se NÃO estiver, copie do serviço principal e adicione manualmente

**Me responda:**
✅ "4 variáveis adicionadas ao workers: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, FAL_API_KEY, REDIS_URL"
